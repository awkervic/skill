# Project Instructions

## 🌌 AI Neat Skill 激活

本项目已配置 **AI Neat Skill (AI 编年史记忆剪枝技能)**。

### ⚙️ 激活协议 (Activation Protocol)

当满足以下任一条件时，必须启动该技能：
1. **用户触发**：输入 `“编年史”`、`“/ai-neat-skill”` 或 `“整理记忆”`。
2. **自动触发**：上下文接近限制或对话超过 20 轮。

### 📜 核心行为树

1. **禁止直接抹除**：严禁直接丢弃历史对话。
2. **编年史压缩**：按 [精确日期] 提炼「核心事件快照」。
3. **记忆同步**：将快照有序追加到 `memory.md`，并在剪枝前完成 **[PENDING]** 任务交接。

详细执行规范请严格参考 [SKILL.md](./SKILL.md)。
