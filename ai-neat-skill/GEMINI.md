# Project Instructions

## 🌌 AI Neat Skill 激活

本项目已配置 **AI Neat Skill (AI 编年史记忆剪枝技能)**。

### ⚙️ 激活协议 (Activation Protocol)

当满足以下任一条件时，必须启动该技能：
1. **用户触发**：输入 `“编年史”`、`“/ai-neat-skill”`、`“整理记忆”` 或 `“同步到根目录”`。
2. **自动触发**：上下文接近限制或对话超过 20 轮。

### 📜 核心行为树

1. **禁止直接抹除**：严禁直接丢弃历史对话。
2. **编年史压缩**：提炼「核心事件快照」并同步至项目根目录的 `memory.md`。
3. **增量总结**：每次变更后在北京时间 `[YYYY-MM-DD HH:mm]` 维度下更新根目录 `Summarize.md`。
4. **记忆持久化**：确保记忆随项目根目录文件走，而非留在技能目录内。

详细执行规范请严格参考 [SKILL.md](./SKILL.md)。
