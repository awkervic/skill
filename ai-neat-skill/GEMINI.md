# Project Instructions

## 🌌 AI Neat Skill 激活

本项目已配置 **AI Neat Skill (AI 编年史记忆剪枝技能)**。

### ⚙️ AI 运行激活协议 (System Prompt)

当用户输入 **“编年史”** 或 **“/ai-neat-skill”**，或者上下文过长需要清理时，请严格遵守以下行为树：

1. **禁止直接抹除**：当上下文过长需要清理时，严禁直接丢弃历史对话。
2. **编年史压缩**：必须将过去 20 轮以上的碎片调试废话，按**事件**提炼为包含 [精确日期] 的「核心事件快照」（每个独立事件占用一行）。
3. **记忆追加**：将快照有序追加到 `memory.md` 中，随后清空原始冗余上下文，释放 Token 空间。

详细执行细节请参考 [SKILL.md](./SKILL.md)。
