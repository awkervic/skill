# AI Neat Skill (AI 编年史记忆剪枝技能)

这是一个用于大模型 CLI 工具（如 Gemini CLI、Claude Code）的无损记忆管理流。

## 项目结构

- `SKILL.md`: 技能定义文件，包含了 AI 运行激活协议和执行细节。
- `ai归档/编年体记忆/memory.md`: (位于项目根目录下的 `ai归档/编年体记忆` 文件夹中) 核心事件快照存储文件。
- `ai归档/编年体记忆/Summarize.md`: (位于项目根目录下的 `ai归档/编年体记忆` 文件夹中) 增量变动总结文件。
- `ai归档/`: (位于项目根目录) 存放临时整理文件与归档资产的文件夹。

## 如何激活

当你在此项目中工作时，AI 会根据 `SKILL.md` 中的协议，在上下文过长时自动执行记忆压缩和剪枝。重要事件将同步至 `ai归档/编年体记忆/memory.md`，变动总结将追加至 `ai归档/编年体记忆/Summarize.md` (北京时间)。
