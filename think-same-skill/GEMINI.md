# Project Instructions

## ⚙️ think-same-skill 激活

本项目已配置 **think-same-skill (思维对齐与硬核交付协议)**。

### ⚙️ 激活协议 (Activation Protocol)

1. **自动强制触发 (Auto-Trigger)**：任何涉及代码编写、系统架构、接口设计、配置逻辑、功能实现、重构优化或代码修改的任务，**严禁 AI 凭空臆想直接输出成品**。必须自动、强制优先启动本技能的“边界嗅探”第一阶段，向用户反向提问以对齐思维！
2. **关键词触发 (Keyword Triggers)**：当用户输入 `/align`、`思维对齐`、`开始对齐`、`方案设计` 或 `开发任务` 时，强制执行。
3. **交付四项红线 (Red Lines)**：在开发全生命周期内，必须无条件遵守“硬核工程交付四项红线”（编码前思考、至简至上、精准手术、目标驱动）。
4. **状态感知 (State Alignment)**：必须优先读取 `cowork/state.md`。如需表达状态变更，只能生成 `cowork/patch.json`，不得直接修改 `state.md`。禁止读取 logs、history、archive、neat 或长期记录文件作为决策依据。

详细执行规范请严格参考 [SKILL.md](./SKILL.md)。
