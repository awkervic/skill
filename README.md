# AI Skills Toolkit 🛠️

这是一个专门为大模型 CLI 编码助手（如 Gemini CLI / Antigravity, Claude Code）设计的自定义技能库（Skills Toolkit）。通过精细化的运行协议与结构化指令，赋能 AI 助手更长效的记忆能力和更卓越的代码交付质量。

---

## 📂 技能模块介绍

本仓库目前包含两个核心技能模块：

### 1. 🧠 AI Neat Skill (AI 编年史记忆剪枝技能)
* **目录**: [`ai-neat-skill/`](./ai-neat-skill/)
* **功能简介**: 解决长对话中上下文溢出与重要历史丢失的问题。通过**无损记忆管理流**，在上下文接近限制时自动触发记忆压缩和剪枝。
* **核心资产**:
  * `SKILL.md`: 技能定义与激活协议。
  * `ai归档/编年体记忆/memory.md`: 存放核心事件与架构决策的长期记忆库。
  * `ai归档/编年体记忆/Summarize.md`: 增量变动总结（基于北京时间）。

### 2. ⚡ Think Same Skill (思维对齐与硬核交付协议)
* **目录**: [`think-same-skill/`](./think-same-skill/)
* **功能简介**: 为复杂工程开发量身定制的思维共鸣与质量保障框架，包含三阶段审核流程与四大工程红线，确保 AI 编写的代码与人类意图完全一致。
* **核心规范**:
  * **思维对齐三闸门**: 边界嗅探 ➡️ 骨架提案 ➡️ 白箱交付。
  * **工程四项红线**: 编码前思考、至简至上、精准手术（禁止无脑重写）、目标驱动。
  * **记忆同步**: 自动衔接并关联 `ai-neat-skill` 维护的记忆系统。

---

## 🚀 如何在 AI 助手中使用这些技能？

当你在支持 **Skills（技能扩展）** 的 AI CLI 工具（如 Antigravity / Gemini CLI 或 Claude Code）中加载本仓库或相关目录作为工作区时，AI 会自动扫描并激活对应的技能。

### ⚙️ 配置文件说明
每个技能目录中包含针对不同 AI 助手的配置：
- **`GEMINI.md`**: 适配 Gemini CLI / Antigravity 的提示词与约束指令。
- **`CLAUDE.md`**: 适配 Claude Code 的运行协议与指令。
- **`SKILL.md`**: 通用的技能描述与执行 SOP 规范。

## 🎨 贡献与定制

您可以根据个人开发习惯和项目规模，自由定制或扩展本仓库的协议：
1. **定制记忆格式**: 修改 `ai-neat-skill/SKILL.md` 调整归档路径与格式。
2. **新增交付红线**: 在 `think-same-skill/SKILL.md` 中增加符合您团队规范的代码检查标准。
