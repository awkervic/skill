# Neat Awker (双轨制轻量化记忆与矩阵修剪协议)

这是一个为大模型 CLI 助手（如 Gemini CLI / Antigravity, Claude Code）量身定制的高速、轻量化记忆管理与文档修剪流。通过双轨制设计，避免长对话中 AI 整理记忆迟钝和耗尽 Token 的问题。

## 📂 项目结构

- `SKILL.md`: 技能定义文件，定义了“只写不读”的编年体轨与“洁癖修剪”的核心规则轨的运行 SOP。
- `GEMINI.md`: 针对 Gemini / Antigravity CLI 的专属激活与运行指令。
- `CLAUDE.md`: 针对 Claude Code 的专属激活与运行指令。

## 🔄 双轨存储资产 (位于项目根目录下的 `ai归档/` 文件夹中)

- **轨一：编年体记录**：
  - `ai归档/编年体记忆/memory.md`: 核心大事记快照。**（只写不读，直接追加，不占用上下文Token）**
  - `ai归档/编年体记忆/Summarize.md`: 北京时间增量日志。**（只写不读，秒级更新）**
- **轨二：核心规则**：
  - `ai归档/核心规则/rules.md`: 实际指导开发的核心规约、红线约束与轻量变更矩阵。**（主动读取，严格控制在 80 行以内，过期规则无情删除）**
- **资产暂存**：
  - `ai归档/`: 用于收纳整理过程中产生的任何临时文件、草稿或中间产物。

## 🚀 如何激活

当您在此项目中工作时，输入 `“编年史”`、`“/neat-awker”`、`“整理记忆”`、`“收尾”`、`“整理文档”` 即可激活本技能。AI 会通过轻量化的“盘点-追加-修剪”流程，秒级完成现场收尾并归档文件，使下次对话进入极速、清爽的状态。
